# 개발 구현 현황

2026년 11월 23일 기준, 두 열용량 데모에서 전역 방정식의 조립, 초기화, 시간 적분과 CSV 저장까지 실행할 수 있다. MHTGR-350 팀 통합변수표를 프로젝트 변수 목록에 반영했다. 실제 정상상태와 냉각재 유량 상실(LOFC) 과도해석에는 구성요소 모델, 운전조건, 검증 데이터가 필요하다.

## 기능별 현황

| 기능 | 상태 | 현재 범위 |
| --- | --- | --- |
| [변수와 포트](../interfaces/) | 구현 | `StateRegistry`가 미분·대수변수의 이름, 단위, 형상, 초깃값, 전역 인덱스를 관리한다. 유체 포트와 열 포트는 등록된 변수를 이름으로 참조한다. |
| [계통 조립](../system/) | 구현 | `SystemAssembly`가 구성요소의 잔차와 연결식의 잔차를 합치고 미지수 개수와 대조한다. 이상적인 두 유체 포트 또는 두 열 포트의 연결식을 제공한다. 다분기 혼합과 유동 역전 모델은 미구현이다. |
| [초기화와 시간 적분](../solvers/) | 구현 | 일치 초기조건과 정상상태를 구한다. 가변 간격 BDF 1~5차, 뉴턴 보정, 유한차분 또는 사용자 지정 야코비안, 밀집 선형계 풀이를 지원한다. 오차가 기준을 넘거나 뉴턴법이 실패하면 스텝을 줄여 재시도한다. |
| [열전달 데모](../examples/demo_system.py) | 실행 가능 | 두 온도와 하나의 열유량을 계산한다. [실행 진입점](../main.py)이 솔버 설정을 읽고 수용된 시점별 결과를 CSV로 저장한다. |
| [원자로 구성요소](../models/) | 구현 틀 | 노심, 열교환기, 압축기, 배관, 플리넘, 압력용기, 경계조건 클래스가 있다. 각 클래스의 변수 등록과 잔차 계산은 `NotImplementedError`로 남아 있다. |
| [물리 모델](../physics/)과 [물성표](../data/properties/) | 미구현 | 유동, 압력손실, 열전달, 중성자 동특성, 물성 모듈에는 계산식이 필요하다. 헬륨·흑연 물성 CSV에는 열 이름만 있다. |
| [변수 목록](variable_registry.csv) | MHTGR-350 통합안·SG/RCCS 보완본 수록 | 기존 288개와 SG/RCCS 보완본에서 추가한 71개를 합쳐 359개 항목의 단위, 배열·인덱스, 모델별 분류, 출처와 확정 상태를 기록했다. 기존 설정·인터페이스와 대응되는 32개 항목에는 코드 참조가 있다. 실제 Component의 상태 등록은 구현 전이다. |
| [원자로 입력과 시나리오](../config/) | 입력 양식 | 형상·운전조건의 `null`은 미정 값을 뜻한다. 정상상태 조건과 LOFC 이벤트 목록은 비어 있다. 변수표에 수록된 정격값·검산값의 적용 조건은 [물리 가정](assumptions.md)에 정리했다. |
| [결과 검증](../validation/) | 지표 구현 | 평균제곱근오차(RMSE), 보존식 잔차, 최대 상대 차이 계산 함수를 제공한다. [벤치마크·실험 데이터 폴더](../data/validation/)에는 비교할 원자료가 아직 없다. |

## 테스트로 확인한 범위

Python 3.14.6에서 `python -m pytest -q -p no:cacheprovider`를 실행해 **27개 테스트가 모두 통과**했다.

- [솔버 테스트](../tests/solver/)는 BDF 계수와 예측식, 비선형 근 계산, 해석해가 있는 DAE, 역방향 적분, 뉴턴 실패 후 재시도를 다룬다.
- [계통 조립 테스트](../tests/integration/test_registry_ports.py)는 중복 변수명 거부, 두 유체 포트의 연결 조건, 열 포트 연결식을 포함한 전역 잔차를 확인한다.
- [열전달 데모 테스트](../tests/integration/test_demo.py)는 수용된 시점에서 잔차식이 성립하는지 확인한다. 기본 설정의 0~5초 구간에서 해석해와 비교한 최대 절대 오차는 두 온도에서 각각 0.001 K 미만, 열유량에서 0.001 W 미만이다.

## 실제 계통 해석에 남은 작업

1. MHTGR-350의 비교 운전점과 벤치마크 자료를 확보하고 형상, 운전조건, 물성 데이터의 적용 범위를 정한다.
2. 각 구성요소에서 통합안 중 실제로 풀 미지수를 정하고 [방정식 목록](equation_registry.csv)에 대응 잔차와 공간 이산화를 명시한다. 잔차 구현 후 단독 시험에서 보존식을 확인한 뒤 포트로 연결한다.
3. 계통 정상상태를 기준값과 비교한 뒤 LOFC 이벤트를 정의한다. 과도응답을 실험 또는 벤치마크 자료와 비교해 적용 가능한 해석 범위를 기록한다.

정격 운전점과 물리 모델 선택에 관한 세부 항목은 [미확정 물리 가정](assumptions.md)에 정리돼 있다.
