# MHTGR-350 변수표와 미확정 모델 입력

2026-11-23 팀 통합변수표의 대상은 MHTGR-350이다. [변수 목록](variable_registry.csv)은 이 표의 288개 항목을 원래 순서로 수록한다. 실제 셀 수, 재료별 물성, 출력분포, 운전 시나리오와 검증용 원자료는 추가 확인이 필요하다.

## 변수 목록 읽는 법

- `proposed_name`은 통합 코드명, `original_notation`은 원문 기호다. `sheet_row`는 엑셀 「전체 변수표」의 행 번호다. `shape`는 원표에 적힌 배열·인덱스 설명이며, 실제 격자 크기는 모델별로 정한다.
- `kind_tentative`, `stage`, `status`, `notes`에는 원표의 분류, 적용 단계, 확정 상태, 연결 조건을 담았다. 모델에 따라 분류가 바뀌는 항목과 포트 별칭도 포함한다. `code_reference`는 「GitHub 이름 대조」에서 대응되는 기존 설정이나 인터페이스를 가리킨다.
- `reference_value`는 정격값, 검산값, 모델 제안값 또는 잔차의 목표값이다. `initial`은 해당 시나리오의 초기조건을 확정한 뒤 채운다. CSV의 빈칸과 YAML의 `null`은 미정이며, 원표에서 명시한 0은 값으로 보존한다.
- `source`는 원표의 근거 표기다. A는 헬륨 물성, B는 1D 유체·DASSL, C는 각주형 구성모델, D는 유체 기기·부품, 3은 노심 열응답·출력, 4는 SG·잔열제거, ‘개요’는 전체 프로그램 개요를 뜻한다.
