# MHTGR-350 변수표와 미확정 모델 입력

2026-11-25 공통 계약 v3에서 포트 stream과 전역 진단 관련 11개
계약 항목을 추가해 CSV/Excel은 372개다. 새 항목의 수치 입력은
문헌 또는 담당자 검증 없이 채우지 않았다. `p_sys`와

저마하수 폐루프의 방정식·소유권·정상 초기화 계약은 확정했으며,

합성 fixture의 rank 결과는 실제 원자로 검증값이 아니다.

2026-11-23 팀 통합변수표의 대상은 MHTGR-350이다. 기존 288개와 「MHTGR-350 SG/RCCS 보완본[4]」에서 추가한 73개가 원자료의 361개 항목이다. [현재 변수 목록](variable_registry.csv)에는 공통 계약 v3의 11개 항목도 들어 있다. SG·RCCS의 확인된 기하와 설계 정격점은 반영했으며, 상세 유로 단면·손실계수·일부 재료 물성, 출력분포, 운전 시나리오와 검증용 원자료는 추가 확인이 필요하다.

## 변수 목록 읽는 법

- `proposed_name`은 통합 코드명, `original_notation`은 원문 기호다. `sheet_row`는 기존 원표에서 확인한 행 번호이며 SG/RCCS 보완본과 공통 계약의 새 행은 비어 있다. `shape`는 배열·인덱스 설명이며 실제 격자 크기는 모델별로 정한다.
- `kind_tentative`, `stage`, `status`, `notes`에는 원표의 분류를 출발점으로 한 현재 계약 분류, 적용 단계, 확정 상태와 연결 조건을 담았다. 원표의 `Algebraic` 잔차 5개는 계약 v3에서 `Residual`로 보정했다. `code_reference`는 기존 설정이나 인터페이스를 가리킨다.
- `owner`, `registry_required`, `runtime_name_pattern`, `implementation_status`는 공통 계약에서 추가한 관리 열이다. 이번에 검토한 항목에 우선 기록했으며 빈칸은 담당자·런타임 형식이 아직 확정되지 않았다는 뜻이다.
- `reference_value`는 정격값, 검산값, 모델 제안값 또는 잔차의 목표값이다. `initial`은 해당 시나리오의 초기조건을 확정한 뒤 채운다. CSV의 빈칸과 YAML의 `null`은 미정이며, 원표에서 명시한 0은 값으로 보존한다.
- `source`는 항목의 근거다. 기존 행의 A는 헬륨 물성, B는 1D 유체·DASSL, C는 각주형 구성모델, D는 유체 기기·부품, 3은 노심 열응답·출력, 4는 SG·잔열제거, ‘개요’는 전체 프로그램 개요를 뜻한다. SG/RCCS 추가 행의 페이지는 보완본[4]의 본문 페이지다. 공통 계약의 새 11개는 `Role 5 공통 계약 v3`로 구분하며 문헌 수치가 아니다.
